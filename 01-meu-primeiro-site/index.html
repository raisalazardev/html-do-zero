Olá, mundo! Esta é a minha primeira página feita com HTML.

As partes de uma página HTML

  • <!DOCTYPE html>: avisa que é HTML5
  • <html>: envolve tudo
  • <head>: informações que não aparecem na tela
  • <body>: o conteúdo que aparece na tela

Como uma tag funciona

Quase toda tag tem abertura e fechamento: <p>texto</p>. O fechamento tem uma barra (/).
