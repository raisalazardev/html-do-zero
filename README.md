## 📖 Sobre

Esta é a trilha **HTML do Zero** do canal **Raí Salazar**. Ela foi feita para quem nunca programou e quer aprender HTML do começo ao fim, com vídeos práticos e código comentado.

Cada vídeo tem a sua própria pasta aqui no repositório, para você acompanhar a aula e comparar com o seu código.

## 🚀 Como usar

1. Baixe o projeto: botão verde **Code** > **Download ZIP**
2. Extraia o arquivo e abra a pasta do vídeo no **VS Code**
3. Abra o `index.html` no navegador
